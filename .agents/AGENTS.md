# Agent Rules - Sustainable Building Materials in Africa (2015-2025)

## Guidelines
- For simple tasks, do not read the whole project docs.
- For code changes, inspect the relevant files, entrypoints, manifests, and tests first.
- Use `index.json` as the repo map when app flow, data shape, prompts, tests, or architecture may change.
- Read `architecture.md` when architecture, runtime behavior, config, dependencies, or user-visible behavior may change.
- Keep context targeted. Prefer grep_search or short file ranges instead of loading everything.
- Adhere to the PRISMA 2020 systematic review standards, Open Science Framework (OSF) registration protocols, and JBI/CASP appraisal criteria established in the project.
- Always write well-detailed, structured git commit messages explaining what was changed, the methodological rationale, and the resulting impact on the review pipeline.
