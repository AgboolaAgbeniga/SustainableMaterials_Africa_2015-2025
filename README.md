## Overview
This repository contains the complete computational workflow, bibliographic logs, screening records, extraction templates, appraisal data, and manuscript deliverables for the systematic review:
**"Sustainable Building Materials in Africa (2015–2025): A Rapid Systematic Review"**  
**Lead Author:** Agbeniga Agboola

The review investigates the 10-year evidence base on sustainable building materials (SBMs) across Africa, evaluating performance, life-cycle impact, economic feasibility, and policy/institutional barriers across five material classes:
1. **Earth-Based Materials** (Compressed Earth Blocks, Rammed Earth, Stabilized Laterite, Adobe)
2. **Bio-Based Materials** (Timber, Bamboo, Hempcrete, Straw Bale, Agro-Waste Composites)
3. **Low-Carbon Cements & Binders** (Limestone Calcined Clay Cement [LC3], Geopolymers, Pozzolans)
4. **Recycled & Waste-Based Materials** (Recycled Aggregates, Plastic Waste Bricks, Slag)
5. **Innovative & Smart Materials** (Phase Change Materials [PCMs], Nanomaterials)

```text

├── 02_SearchLogs/          # Search strategies, raw exported .ris citations, and deduplication records
├── 03_Screening/           # Title/abstract and full-text eligibility screening logs
├── 04_DataExtraction/      # 29-field extraction templates and standardized data dictionary
├── 05_QualityAppraisal/    # Methodological risk of bias assessments using JBI and CASP tools
├── 06_Analysis/            # Thematic synthesis tables, cross-country metrics, and figures
├── 07_Manuscript/          # Paper drafts and final peer-reviewed journal submission packages
├── 08_Supplements/         # PRISMA 2020 checklists, flow diagrams, and supplementary data tables
├── resources/              # Reference datasets (including AJOL structured metadata)
├── IMPLEMENTATION_PLAN.md  # Detailed institutional execution roadmap
├── architecture.md         # System and methodology architecture
└── index.json              # Structural repo data map
```
